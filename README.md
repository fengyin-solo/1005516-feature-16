# 制药企业洁净区与批生产记录管理平台

面向洁净区环境监测、批生产记录编录、物料放行、偏差与变更控制、灭菌与清洁验证、成品检验与年度质量回顾的一体化药品生产质量管理工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `pharma-cleanroom:entries:v2` 这一项，或调用 `resetModule(模块)`。

### 供应商审计的台账口径

供应商审计模块在通用服务之外有一套专用台账规则，集中在
`frontend/src/data/audit-ledger.ts`（对应 localStorage 键 `pharma-cleanroom:audit-*-ledger`）：

- **筛选**：审计编号（包含匹配）、审计方式（下拉）做条件；缺陷项数按下限/上限卡区间；
  整改期限按起始/截止卡区间并支持升序/降序排序（未填或非法的期限沉底）。
  条件本身非法（非整数、上下限颠倒、假日期如 2026-02-30、起止颠倒）会被打回并指明是哪一栏；
  条件合法但查不到时，逐栏报告是哪一栏把结果卡成 0 条。
- **状态机**：待审计 → 审计中 →（已通过 / 需整改 → 复核通过），只能逐档往下流转，
  跳级、回退一律拒收。
- **物料类别排期**：按物料类别周期（原料药 12 月、辅料 6 月、包装材料 12 月、耗材 24 月），
  自同类别最近一次实际审计日期起算下一次计划审计日期。
- **缺陷核定台账**：缺陷项数由审计组核定，审计单与核定台账不一致时（含审计方式）按台账口径
  自动统一；书面审计缺陷项数上限 5、远程审计上限 3，现场审计不设上限。
- **整改期限留档**：登记、整改跟踪、行内修改几个入口共用同一份值，且只能通过
  `setAuditDeadline` 写入；每次改动追加留档；非法日期（含 2 月 30 日这类假日期）、
  早于审计日期的值打回重填。
- **复核去重**：同一份审计重复复核只算一次，复核台账按审计编号去重。
- **培训落地**：审计结论含「培训」时，状态流转到终态自动在人员培训台账登记
  （培训编号 `TRAI-<审计编号>`，同一审计只落一次），人员培训页的「来源审计编号」列可溯源。
- 页面底部「整改期限留档 / 缺陷核定台账 / 复核台账 / 人员培训台账」四个页签可直接查看台账内容，
  「恢复演示数据」会把审计数据与三本台账一并重置。
